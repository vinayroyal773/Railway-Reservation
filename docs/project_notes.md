# Project Notes

## Objectives
1. Connect railway stations and a central reservation server.
2. Find efficient routes using Dijkstra.
3. Maintain routing information using Distance Vector.
4. Detect transmission errors using CRC.
5. Demonstrate Sliding Window and Go-Back-N.
6. Simulate link failure and route recovery.
7. Evaluate packet loss, delay and throughput.

## Suggested 7-member division
1. Frontend UI
2. Reservation frontend/API
3. Dijkstra routing
4. Distance Vector routing
5. CRC + Sliding Window + Go-Back-N
6. Link Failure + Error Recovery
7. Database + Integration + Performance
